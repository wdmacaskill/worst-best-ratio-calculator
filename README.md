# WORST:BEST ratio calculator

An interactive calculator for how much worse the worst feasible future is than the best feasible future is good, once moral uncertainty is taken into account. You set credences in classical utilitarianism (CU), negative-leaning utilitarianism (NLU) and a view that is bounded above but unbounded below (BAUB), choose how to normalise them, and read off the WORST:BEST ratio R. Companion to Will MacAskill's note 'How negative-leaning should we be, given moral uncertainty?'. Built by Claude for Forethought, October 2026.
